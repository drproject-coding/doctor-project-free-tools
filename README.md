# Doctor Project free tools

Files loaded by the free tools on doctor-project.com, served through jsDelivr.

- `akeneo-rules-checker/akeneo-rules-checker.v11.min.js`: the Akeneo Rules Checker used on
  https://doctor-project.com/free-tools/akeneo-rules-checker. It runs in the visitor's browser;
  no rules file is uploaded anywhere.

The site loads a fixed commit, so a change here never reaches the site by accident.
